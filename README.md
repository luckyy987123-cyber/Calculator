# Calculator

A simple calculator program developed using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero
- Easy to use

## Requirements

- Python 3.x
- VS Code (recommended)

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
